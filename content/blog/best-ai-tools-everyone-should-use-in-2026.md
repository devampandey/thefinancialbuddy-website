There's no shortage of "best AI tools" lists, and most of them are really just affiliate link roundups dressed up as advice. This one is simpler: what's actually worth using right now, organized by what you're trying to get done.

## S Tier - general-purpose assistants

**Claude, ChatGPT, and Gemini** are the tools most people should start with. All three can handle writing, research, brainstorming, and light coding, and the differences between them come down to preference more than capability at this point. Claude tends to handle long documents and large codebases without losing the thread. ChatGPT has the widest plugin/integration ecosystem. Gemini has the tightest integration if you're already living in Google's ecosystem (Docs, Sheets, Gmail).

Practical advice: pick one as your default, but don't be precious about it — for a specific task, it's worth trying a second one if the first result feels off.

## A Tier — specialists worth adding

**GitHub Copilot** and **Cursor** are the standouts for coding — Copilot for in-editor autocomplete and boilerplate, Cursor for larger multi-file changes and refactors. If you write any code regularly, one of these pays for itself quickly in time saved.

**Perplexity** is worth using specifically for research questions where you want cited sources rather than a confident-sounding paragraph with no way to verify it. It's not a replacement for a general assistant, but it's the better tool for "what's the current state of X."

## B Tier — useful, but not essential

**Copilot for Microsoft Office**, **Notion AI**, and **Zapier's AI features** are genuinely useful if you're already living inside those tools every day — summarizing a missed meeting, drafting inside a doc, or automating a repetitive workflow. They're not tools you'd seek out on their own; they're upgrades to software you already use.

## C Tier — proceed with skepticism

Most single-purpose "AI wrapper" apps that resharpen a general model for one narrow use case are rarely worth a separate subscription. Before paying for one, try doing the same task with whichever S-tier assistant you already use — it can usually get you 90% of the way there for free.

## The actual takeaway

You don't need five AI subscriptions. Pick one general-purpose assistant, add a coding tool if you code, add Perplexity if you research things often, and stop there. The tools that matter are the ones you'll actually open every day — not the ones with the flashiest launch video.
